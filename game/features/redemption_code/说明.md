# 兑换码玩法

本玩法把正式内容中登记的公开兑换码解析为账号权益，再通过统一奖励结算把货币、堆叠物品、随机装备和随机武器
原子发放到当前唯一角色。代码活动按账号限制领取次数，数据库只保存代码摘要和领取凭据。

装备与武器直接使用探险共用的正式实例生成器。`VIP666` 为六个装备槽分别随机底座，并额外随机一把
武器；各实例独立生成词条和自然套装印记，只筛选普通品质，不固定底座族、套装或武器流派。

`VIP888` 每个账号限领一次，固定发放六种恢复药和七种特殊消耗品各一份。奖励不包含抽奖签、
突破凭证、兑换材料、套装图纸、铭刻之羽、武器装备或背包战利品。

命令组件只负责输入与展示，不读取数据库，也不决定奖励数值。活动登记、有效期、额度和奖励版本均以
`game/content/catalog/redemption_code` 的可信定义为准。
