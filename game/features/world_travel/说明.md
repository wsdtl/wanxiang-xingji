# 世界移动业务

`WorldTravelFeature` 是角色在当前真实世界内移动的唯一写入口。它读取角色 `world_id`，通过
`WorldRuntimeCatalog` 把当前世界的独立物理锚点解析为空间坐标，并拒绝主要行动期间移动。
行动占用只读取统一玩家活动投影；探险运行和自动休整均明确返回 `exploring`，正式休息等其他主要行动
返回 `main_action_occupied`，命令层据此提供对应的停止或查看入口。

跨消息按钮使用 `WorldLocationIntent` 携带 `world_id`、`anchor_id`、主功能和绑定版本。执行时任何一项
与当前事实不一致都会拒绝旧按钮；手动输入地点名称则始终按角色当前世界重新解析。

本业务不开始探险、不结交人物，也不解释地点内容。具体业务只声明目标锚点，移动成功后再执行自己的规则。
