# 组队挑战

组队挑战是队伍关系之上的独立玩法，不把组队域改造成战斗域。归航公约把队伍承认为跨界协同档案，
界门只在挑战期间生成一次临时战斗投影。

- `PartyFeature` 只负责队伍成员、队长、站位和准备状态。
- `PartyBattleFeature` 保存当前锁定的组队首领、准备指纹、尝试次数和每日奖励状态；队伍准备标记与挑战
  指纹由它在同一个工作单元提交，命令层不能分两次写入。
- 首领从所有开放世界各自的组队首领池中随机抽取，个人探险首领不进入这个池子；来源世界只决定
  首领身份、名称和表现，不改变奖励价值。
- 队员不需要处于同一个世界；挑战不会修改任何成员的世界身份、地图位置、跃迁状态或原世界进度。
- 战斗复用公共战斗核心；三名玩家最多各带当前配装绑定的伙伴进入同一场战斗。
- 失败保留同一个首领供重试，清空准备指纹并结算真实资源损失。
- 锁定首领携带生成时的内容指纹；内容切换后旧指纹首领立即失效，不能进入准备或战斗，队长可直接
  重新选择当前版本的首领。组队首领不涉及已消耗资产，因此不阻塞内容发布。
- 胜利后每名玩家独立抽取自己的奖励；每日前两次胜利正常发放，之后只能助战不发成长和物品奖励。
- 玩家奖励、资源变化、挑战状态和完整战报在同一个 SQLite 工作单元中提交。
- 发起挑战前逐个读取统一玩家活动投影；队员探险与其他主要行动分别返回准确状态，不能把自动休整误报
  为普通休息。
- 完整战报通过统一战报服务保存明细 3 小时、摘要 12 小时，QQ 只返回摘要和公开链接。

命令入口仍归属于 `game/cmd/组队`：`组队挑战`、`选择组队挑战 等级`、`开始组队挑战`。
