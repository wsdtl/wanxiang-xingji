# 特效组件

`特效` 只负责把当前配装事实连接到正式内容目录，不复制战斗公式或随机词条数值。

- `特效`：列出当前角色真正生效的能力、武器核心、随机词条和套装效果。
- `特效 名称`：展示全部正式档位，并标出当前实际档位、滚值和来源装备。
- `特效 全部 [页码]`：按每页最多 50 项浏览正式机制图鉴。

机制名称与简介来自当前世界皮肤；概率、条件、持续时间、目标和数值公式由 `MechanicProjector` 从冻结内容目录统一翻译。
同一机制中的重复操作会合并展示并明确保留执行次数，公式中的效果来源、作用目标和资源名称必须跟随真实规则与当前世界。
目录出现未支持的操作、条件或数值表达式时必须失败，不能回退显示内部 ID。
