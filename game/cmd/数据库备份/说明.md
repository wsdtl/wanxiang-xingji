# 数据库备份二级组件

本组件没有玩家命令，只通过框架 `Scheduler` 注册正式数据库备份任务。

## 固定策略

- 每 8 小时执行一次，同一时间最多运行一个实例；调度器积压的多次执行会合并为一次。
- 只允许备份当前 `wanxiang_xingji.db`，不会处理 `message_console.db`。
- 备份保存在主库同级的 `backups/`，文件名格式为
  `wanxiang_xingji_YYYY-MM-DD_HH-mm-ss.db`。
- 成功生成新备份后只保留按文件名排序最新的 3 份；其他名称的文件不会被轮换删除。

## 一致性

二级组件通过 `GameServices` 调用 SQLite 持久化适配器的在线 Backup API，能够合并主文件与 WAL 中已经
提交的数据。备份先写入唯一临时文件，切换为独立 `DELETE` 日志模式并通过 `PRAGMA quick_check` 后，
才原子替换为正式备份文件。备份生成或校验失败时不会触发历史轮换。

恢复时应先停止服务，保留故障现场，再用选定的备份文件替换正式主库并重新启动验证。
